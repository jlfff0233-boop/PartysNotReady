# PENDING_DECISIONS

## PURPOSE

구현 전에 사용자 결정이 필요한 항목의 단일 목록입니다. 아래 권장안은 승인되지 않았으며 문서 작성 승인을 기능 정책 승인으로 해석하지 않습니다. 확정 시 해당 System 문서에 계약을 반영하고 이 목록에서는 제거하거나 결정된 계약으로 연결합니다.

## CONFIRMED_BOUNDARY

- 확정된 구매 / 반입은 [REWARD_ITEM](System/REWARD_ITEM.md), 효과 / 입력 / 차감 / HUD는 [SUPPORT_ITEM_CATALOG](System/SUPPORT_ITEM_CATALOG.md#runtime_contract), 재고 / 리필은 [PARTY_PREPARATION](System/PARTY_PREPARATION.md#ingredient_refill)을 따릅니다. 이 절에서는 해당 계약을 다시 설명하지 않습니다.

## SHOP

상점의 구매 / 보관 / 반입 / 시작 실패 복원 계약은 [REWARD_ITEM](System/REWARD_ITEM.md#shop_plan)을 따릅니다. 현재 판매 설정은 양수 가격만 허용하며 무료 상품은 지원하지 않습니다. 구현 / 사용자 확인 범위는 DONE에 기록합니다.

| 결정할 내용 | 권장안 / 대안 | 영향 범위 | 결정 시점 |
| --- | --- | --- | --- |
| 상품 정렬 | 첫 구현은 판매 목록 순서. 드롭다운 정렬 기준은 미정 | 상점 목록 UI | 정렬 기능 구현 전 |
| 타이틀 / 로비 확장 | 타이틀은 시작 / 설정 / 종료 버튼 예정. 현재 Canvas_Start 진입, UI 준비 후 홈 연결. 멀티 모집은 별도 | 화면 구성 / 네트워크 | 해당 UI 구현 전 |

| 결정할 내용 | 권장안 / 대안 | 영향 범위 | 결정 시점 |
| --- | --- | --- | --- |
| 목표 개수 / 필요 수량 | 단계 기본 범위와 개별 재정의 구조는 확정. 실제 수치는 미정이며 기존 최소 1 / 3 / 5는 검토값 | 미션 생성 / 표시 / 완료 판정 | 플레이 튜닝 시 |
| 제작 / 배치 연관 선정 | 단계 안 중복 금지와 단계 간 후보 공유는 현재 계약. 제작 / 배치 목표를 연관해 선정할지 미정 | 선정 알고리즘 | 선정 보완 시 |
| 패널 표시 | 상점 / 아이템 선택 시 시작 패널을 유지할지 재논의 | 타이틀 UI | UI 보완 시 |
| 제작 대응표 | 레시피별 기본 설정에 대응하는 난이도별 데이터 구조는 확정. 각 대응과 수치는 미정 | 제작 판정 / 뒤집개 기본값 복원 | 제작 설정 연결 전 |
| 동시 발생 상한 | 도입 여부와 제한 단위 결정 필요 | 후보 선택 / 방별 압박 | 난이도 검증 시 |

## DATA_IMPORT

현재 임포터의 입력 / ID / 관리 필드 / Map 교체 / 부분 실패 계약은 [DATA_IMPORT](System/DATA_IMPORT.md)를 따릅니다. 아래 선택지는 기존 도구의 미구현 항목이 아니라 신규 대상 확장 시의 결정 후보입니다.

| 결정할 내용 | 권장안 / 대안 | 영향 범위 | 결정 시점 |
| --- | --- | --- | --- |
| 신규 대상 | 기존 허브에 없는 설정의 임포트 필요성과 우선순위 | 데이터 구조 / 작업 순서 | 추가 임포터 착수 전 |
| 입력 형식 | 기존 JSON / CSV 재사용 가능성을 먼저 검토, 복합 참조 표현 방식 결정 | 작성 편의 / 파싱 | 입력 명세 전 |
| 식별 / 참조 | 이름과 구별되는 안정된 ID 권장. 기존 에셋 매칭·이름 변경 처리 결정 | GUID 보존 / 재임포트 | 생성·갱신 구현 전 |
| 관리 필드 | 임포터가 덮어쓸 필드 명시, 나머지 수동 값 보존 권장 | 수동 설정 손실 방지 | 입력 명세 전 |
| 목록 갱신 | Map 전체 교체 / 병합 선택 필요. 원본에서 빠진 에셋 자동 삭제는 제외 권장 | 목록 참조 / 누락 | 적용 구현 전 |
| 실패 처리 | 사전 검증 오류는 적용 중단 권장. 적용 중 실패는 기존 도구처럼 부분 결과 보고 또는 롤백 지원 중 선택 | 복구 / 구현량 | 적용 구현 전 |

## TUNING

- 가격, 효과 지속시간 / 사용 횟수 / 배율, 점수 보상, 발생 확률은 최종 수치 미정입니다. 설정 구조와 임시 검증값을 구분합니다.
- 맵 동선 / 실제 모델 크기 / 애니메이션 시간이 나온 뒤 최종 조정합니다. 모든 수치 확정을 다음 구조 구현의 선행 조건으로 두지 않습니다.
- 멀티플레이 권한은 이번 싱글 시스템 정리 범위에서 제외합니다. 기존 MULTIPLAYER 문서의 후속 범위를 유지합니다.
