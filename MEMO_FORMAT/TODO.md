## MANAGER_IMPLEMENTATION

- **설정 데이터 확인 후보:** 키 목록이 null이면 복사 중 Clone에서 예외가 나지만, 실제 저장 / 로드 경로에서 null이 발생하는지는 미확인입니다. 먼저 발생 가능성을 확인하고, 발생하지 않으면 방어 코드를 추가하지 않습니다. 수정이 필요하면 초기 설정 준비와 데이터 복사 전에 구성 검사를 배치하되, 최초 해상도 0을 허용하는 초기 검사와 최종 적용 검사를 구분합니다. 잘못된 저장값을 덮어쓰거나 포괄적인 catch로 숨기지 않고 실패 보고와 부분 연결 정리를 수행합니다. 빈 키 목록 / 최초 해상도 0 / 정상 저장값의 적용을 유지해야 합니다.
- **설정 초기화 정리 검증:** 초기 설정 준비 / 적용 실패와 예외 시 부분 연결이 정리되는지, 정상 초기화와 종료가 유지되는지 확인합니다.
- **코인 / 아이템 저장 통합 검증:** SaveManager 경로에서 기존 저장 키 / 코인 이전, 구매, 반입 차감과 취소 복원, 단회 보상, 저장 후 재실행 로드와 타이틀의 편집 모드 저장 디버그를 확인합니다. 현행 책임은 [매니저 / 풀링](System/MANAGERS_AND_POOLING.md)을 따릅니다.
- 설정 UI의 키 재지정 입력과 번역 콘텐츠 연결, 음량 / 화면 / 키 설정의 저장 후 재실행을 확인합니다.
- 씬 / 네트워크 매니저는 후순위입니다.

- 재고 TMP의 등록 / 플레이어·적 획득 / 재보충 / 즉시 보급 / 디버그 소진 / 종료 갱신, 마지막 재고 경합 / 복수 적 사용 / 예약 취소 / 중복 차감 / 회수 후 미복원 / 풀 반환을 확인합니다.

## ENEMY_KIDNAP

- 최신 사용자 확인은 [DONE](DONE.md#2026-10-10-여우-도주--토끼-복원--이동-진단), 증상과 원인 / 설정 조정 근거는 [ERROR](ERROR.md#여우-자동-우회-후-방향-반복-변경과-벽-관통)을 따릅니다. 추가 경로 수정 없이 현재 설정으로 반복 확인합니다.
- 방향 반복 변경 / 벽 관통이 재발하면 선정 목록과 실제 동선, 구간 전환 / 재시도, NavMesh 차단과 Agent / Transform 동기화를 대조합니다. 곰 퇴장 중 벽 통과와 적별 반복 이동도 별도로 확인합니다.
- 실제 입구 도착에서만 납치 완료하는지, 경로 실패 / 구출에서 포획 해제와 결과가 한 번만 적용되는지 확인합니다. 공격 상태 진입 보정 후 판정 시점과 포획 중 버둥거림도 재확인합니다.
- 시간 초과 스턴과 전체 게임 종료에서 도주 / 포획 수명이 정리되는지 확인합니다.
- 파티룸과 현관이 가까운 배치에서 실제 도주 시간과 구조 입력 시간을 비교합니다. 현재 설정 수치와 확인 범위는 위 DONE 기록을 따르며 최소 거리 / 보장 시간을 새로 확정하거나 맵 재배치를 자동 작업으로 포함하지 않습니다.
- 방별 경유점 수동 할당은 사용하지 않습니다. 기존 RouteGraph의 노드 / 단방향 연결과 공용 입구 참조로 자동 우회합니다. 계약은 [ENEMY_PATHFINDING](System/ENEMY_PATHFINDING.md#kidnap_escape)을 따릅니다.

- 최소 체류시간 / 실패 후 대기 / 방 밖 복귀 / 반복 포획과 결과 경합 확인.
- 음악 연결 후 조건 종료 시 일반 행동, 춤 중 포획, 구조 후 착지 뒤 음악 재평가, 종료 시 구독 / 애니메이션 정리 확인.
- 플레이 결과로 이동 수치 / 확률 조정. 변장 적과 오인 대응 감정 상태는 후순위.
- 음악 반응 재개 순서: 음악 출력 왜곡과 정책 / 스피커 구조 검토 → 음악 담당 구현 → NPC 상태 / 춤 연결 → 플레이 수명 연결과 정적 검토 → 에셋 연결 후 포획 / 구조 연계 실행 확인.
