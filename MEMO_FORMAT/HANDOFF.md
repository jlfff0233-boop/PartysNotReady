﻿# 작업 안내

- 이 문서는 작업 진입 링크만 제공합니다. 완료 이력과 사용자 확인은 [DONE](DONE.md), 작업 상태와 남은 검증은 [TODO](TODO.md)를 단일 원본으로 사용합니다.
- 작업 시작: [TODO의 현재 우선순위](TODO.md#current_todo). 연결 / 검증 / 에셋 대기 등 남은 작업도 TODO에서 확인합니다.
- 큰 개발 순서: [ROADMAP](ROADMAP.md).
- 시스템 문서와 작업 규칙의 진입점은 [README](README.md)를 따릅니다. 개별 기능의 계약과 설정은 해당 문서에서 확인합니다.

## 새 채팅방의 첫 작업

1. 현재 작업 환경을 확인하고 AGENTS / GUIDELINE / TODO의 현재 작업을 읽습니다.
2. 최신 사용자 요청에 해당하는 System 절과 DONE의 확인 범위를 대조하고, 이미 완료한 작업과 보류 작업을 다시 착수하지 않습니다.

## 재개 시 확인 기준

- 문서 관리 / 코드 변경 / Unity 파일 보호 / 빌드 기준은 [GUIDELINE](GUIDELINE.md)을 따릅니다. 이 문서에는 임시 인계 특이사항만 추가하며 공통 규칙과 작업 목록을 복제하지 않습니다.
