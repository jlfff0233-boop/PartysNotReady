# SPACE

## PURPOSE

핵심 공간의 역할, 준비 업무, 환경적 약점과 포식자 연계를 관리합니다.

## WORK_CONNECTIONS

창고의 재료 / 식기는 조리실로, 완성 음식과 창고의 장식은 파티룸으로 운반합니다. 의상은 창고 / 드레스룸과 손님 업무를 연결하는 후속 범위입니다. 실제 방 인접도 / 문 연결 / 정확한 이동 동선은 아직 미정이며, 음식 / 배치의 현재 구현은 [PARTY_PREPARATION](PARTY_PREPARATION.md)을 따릅니다.

## CURRENT_DECISION

### 조리실

- 역할: 음식과 음료 준비
- 업무: 음식 조리 / 완성 음식 운반 / 필요 시 음료 준비
- 약점: 닫을 수 없는 창문 / 조리 타이밍 중 시선 고정 / 냄새와 개방부로 인한 침입
- 연계: 까마귀 / 음식에 관심을 보이는 곰

### 창고

- 역할: 식기 / 장식 / 재료 / 의상 등 준비물 보관과 공급
- 업무: 요청 물품 찾기 / 운반 / 필요 시 정리
- 약점: 원래 복잡하고 어질러져 오브젝트 변화 탐지가 가장 어려움
- 연계: 담비

### 파티룸

- 역할: 파티가 열리는 중심 공간
- 업무: 테이블 세팅 / 장식 / 음식 배치 / 음악 / 피해 복구
- 약점: 다수 NPC와 오브젝트 / 잦은 이동 / 음악으로 인한 시청각 정보 과부하

### 드레스룸

- 역할: 초대 토끼의 의상 준비와 적용
- 업무: 요청 의상 선택 / 적용 / 필요 시 액세서리 준비
- 약점: 옷장 / 커튼 / 옷더미 / 가림막 등 은신 장소가 많음
- 연계: 여우

## PENDING

- 공간별 정확한 배치와 이동 동선
- 침입구 / 은신처 / 상호작용 지점 수와 위치
- 플레이어가 만든 정상 변화와 포식자 이상 변화의 시각적 구분 기준

## UPDATE_RULE

- 공간 역할 / 고유 약점 / 포식자 연계가 확정 또는 변경될 때 갱신합니다.
