# IMPOSTOR

## PURPOSE

변장 적의 유형, 판별과 대응, 원본 NPC 처리, Mood 영향과 책임 경계를 관리합니다.

## TYPE_COMPARISON

후순위 확장 설계이며 구현 완료를 뜻하지 않습니다. 세부 수치 / 판별 정책은 PENDING에 둡니다.

| 유형 | 원본 NPC | 해결 |
| --- | --- | --- |
| 복제형 | 그대로 활동 | 같은 외형으로 추가 등장한 변장 적을 올바르게 지목 |
| 대체형 | 은신처에서 임시 비활동 | 실제 원본을 조사 / 발견하고 복구 |

발각 후 Exposed → Escape → End로 퇴장합니다. 대체형 강제 종료 / 비활성화 / 씬 종료에서도 원본을 복구하되 정상 발각 보상 / 해결 확정과 구분합니다. 숨긴 원본은 잔존 수와 Safety를 유지하고 일반 행동 / 포식자 표적에서만 제외합니다.

## CURRENT_DECISION

- 변장 적은 담비와 별개의 너구리 계열 Enemy이며 후순위 확장 대상으로 둡니다.
- 직접적인 Preparation / Safety 피해보다 NPC 사이에서 Mood를 악화시키는 사회적 교란을 담당합니다.
- 복제형과 대체형은 서로 다른 유형입니다. 복제형은 원본과 같은 외형으로 추가 등장하며 지목으로 해결합니다.
- 대체형은 원본 NPC를 숨기고 대신 활동합니다. 실제 원본 은신처를 조사해 발견하면 해결합니다.
- 숨겨진 원본은 납치나 게임 이탈이 아닌 임시 비활동 상태이며 잔존 NPC 수와 Safety를 유지합니다. 일반 행동과 포식자 표적에서는 제외합니다.
- 발각 자체가 해결이며 이후 도주는 퇴장 절차입니다.
- 정상 NPC 오인 지목은 약한 Mood 패널티와 재지목 제한을 적용합니다. 변장 적 장기 방치 손실은 오인 1회의 손실보다 크게 둡니다.
- 최소 상태 흐름은 `Disguised → Exposed → Escape → End`입니다.

## RESPONSIBILITY_BOUNDARY

- 상위 Enemy / Presenter: 유형 구성 / 대상 선정 / 기능 연결과 실행 순서
- Disguise: 외형 대상과 적용 / 해제
- Clone: 원본 유지와 지목 결과 연결
- Replacement: 은신처 선택 / 원본 비활동 / 발견 / 복구
- Enemy State: 현재 행동 단계와 전환

대체 원본 복구는 State 수명과 분리해 강제 종료 / 비활성화 / 씬 종료에도 보장합니다.

## PENDING

- 외형 복사 방식 / 출현 빈도 / Mood 수치 / 재지목 제한
- 판별 징후 / 복제형 비교 동선 / 은신처 조건
- 도주와 재출현 / 멀티플레이 지목과 조사 권한

## UPDATE_RULE

- 변장 적의 유형 / 대응 / NPC 처리 / Mood / 상태와 책임 경계가 변경될 때 갱신합니다.
