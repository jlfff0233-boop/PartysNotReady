# Rabbit Party 프로젝트 메모

이 폴더는 Rabbit Party 프로젝트의 공식 메모입니다.

- 기본 조회는 [GUIDELINE.md](GUIDELINE.md)와 [TODO.md](TODO.md)입니다. 해당 작업의 System 절만 추가로 읽고 나머지는 필요할 때 조회합니다.
- 전체 진행 단계는 [ROADMAP](ROADMAP.md), 현재 작업과 보류 상태는 [TODO](TODO.md#current_todo), 미정 정책은 [PENDING_DECISIONS](PENDING_DECISIONS.md)에서 확인합니다.
- 프로젝트 전역 기획과 시스템 경계는 [DECISION.md](DECISION.md)를 기준으로 판단합니다.
- [System](System)은 현재 기능 계약과 설계 후보, [DONE](DONE.md)은 구현 / 실행 확인 결과를 관리합니다. 설계 후보는 착수 승인으로 해석하지 않으며 HANDOFF는 임시 인계 안내만 유지합니다.
- 진행을 실제로 막았던 오류는 [ERROR.md](ERROR.md)에서 관리합니다.
- 이 폴더의 Markdown 문서만 공식 메모로 사용합니다.
- 코드 작성 스타일은 [GUIDELINE](GUIDELINE.md#code_style), 아이템별 상세 기획은 [SUPPORT_ITEM_CATALOG](System/SUPPORT_ITEM_CATALOG.md)를 참조합니다.
- 제작 지원 도구는 [EDITOR_TOOLS](System/EDITOR_TOOLS.md), 데이터 임포터는 [DATA_IMPORT](System/DATA_IMPORT.md)를 참조합니다.
- UI / 화면 / 캐릭터 연출 계획은 [UI_PRESENTATION](System/UI_PRESENTATION.md), 오디오 연결 계획은 [AUDIO](System/AUDIO.md)를 참조합니다. 계획과 코드 구현 완료를 구분합니다.
